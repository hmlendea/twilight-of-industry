## Event Rules

- Edit only the YAML frontmatter `events` list unless explicitly requested otherwise.
- Keep every `events` list in strict alphabetical order.
- Do not include years, date ranges, or calendar dates in event names.
- Do not use `Global` or `World` in event names.
- Prefer location-specific scope in event names such as `Terran`, `Martian`, `Lunar`, `Titanian`, `Europan`, or another explicit location.
- If an event is phrased as `... on [WorldName]`, rewrite it as `[WorldName_adj] ...` instead.
- Do not use possessive world-name forms such as `Mars’s` or `Luna’s`; prefer adjectival forms such as `Martian` and `Lunar` instead.
- If the text gives an official programme, policy, convention, initiative, act, council, or fleet name, use that canonical name rather than paraphrasing it into a more generic event label.
- If the chapter body gives a named event without a leading article, keep that exact form in frontmatter; do not prepend `The` unless it is part of the canonical name.
- For multiworld response sequences, name the underlying crisis or failure on the affected world rather than the response coalition, unless the response title is itself the canonical name used in the text.
- When a response sequence is centred on one world but assisted by others, prefer the affected world's adjective plus the concrete failure noun, not a list of every participant world.
- For accession events, use the plain form `Roman Accession` unless a more specific Roman-scoped label is explicitly needed.
- When accession is the event, name the accession itself, not the applying state or person.
- Prefer `IRF` terminology over generic `Resonance` wording when the event concerns the inertial resonance field.
- Do not use generic event names when a specific scope is known.
- Avoid process-verb labels such as `begins`, `ends`, or `progresses`; prefer stable noun phrases.
- Avoid process-style suffixes such as `Expansion`, `Effectiveness`, `Reinstatement`, or `Acceleration` when they merely describe programme status or change over time; prefer the underlying event, policy, or programme name instead.
- Avoid generic orbital labels such as `Orbital Recovery`; specify the orbital context (for example `Terran Orbital Debris Recovery`).
- Use `The Lunar Great Library` instead of `The first Lunar Library disaster` style labels.
- Keep recurring event arc names consistent across all chapter files.
